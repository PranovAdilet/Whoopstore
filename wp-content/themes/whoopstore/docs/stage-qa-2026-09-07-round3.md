# Стейдж QA — раунд 3 (2026-09-07, исправление ошибки раунда 2)

## Признание ошибки

В раунде 2 я проверял ТОЛЬКО элементы с классом `__media` (по одному на
секцию) и по факту пропустил **отдельные слои больших декоративных/атмосферных
фоновых фотографий**, которые в Figma лежат в общей канве без привязки к
конкретному `__media`-контейнеру, плюс поверил комментарию предыдущего аудита
про "декоративные окружности" в компакт-ремешках, не перепроверив это по
своим же сырым Figma-дампам. Спасибо, что указали конкретные секции — по ним
нашлось ещё **4 подтверждённых пропуска**, плюс переоценка одного пункта,
которую я в раунде 2 закрыл ошибочно.

Все находки ниже перепроверены заново напрямую в `raw/*.code.tsx.txt` (реальные
данные из Figma, не предположения) и сверены построчно с текущим HTML
стейджа (тот же свежий `/tmp/stage.html`, `theme.css` с `Last-Modified` 08:02
GMT — актуальность стейджа уже подтверждена в раунде 2, повторно не проверял).

## Второстепенная находка (ниже приоритетом)

В Figma у нескольких секций (hero, balance-banner, no-display, "Персонализируйте")
есть decorative-слои с именем `"Ellipse"` — судя по паттерну использования в
других местах (обёртка `<img src=".svg">` как soft-glow) это, вероятно, мягкие
цветные засветы/блики за контентом. На стейдже в `theme.css` **нет ни одного**
`blur`/`radial-gradient` — таких эффектов нет вовсе. Не проверял на 100% (это
могут быть просто градиентные SVG-фигуры без блюра, а не обязательно "глоу"),
но раз уж заметил при повторном проходе — фиксирую как низкоприоритетный пункт
на будущее, не как подтверждённый баг.
